# UEdit
A python save editor for Undertale that is currently in WIP.
For now, it supports having both editable undertale.ini and file0. Additional support for Deltarune or fangames like Undertale Yellow will come out in future updates.
The sole reason why there are two updates so fast is because I made them before making a repository.
Windows exclusive (for now).

# Requirements
UEdit requires following:
- Python (obviously; pref. 3.10)
- colorama

# Functionality
For undertale.ini, you can choose the following:
- Name
- LV
- fun
- Kills
- BC (which is the total of your item count)
- Time
- Room

For file0:
- Flags 1 - 549 with manual input (https://docs.google.com/spreadsheets/d/1kQZ3FvunKb2PSkFkjVzK3BhIDLvIZkf-tsKGhuUa_0A/ for reference)
